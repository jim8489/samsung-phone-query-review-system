# Assessment requirement mapping

| Requirement in the PDF | Implementation in this project | Demonstration / acceptance |
|---|---|---|
| Scrape 10–15 Samsung phones from GSMArena using BeautifulSoup, Scrapy or Selenium | `app/scraper/browser.py` uses Selenium visible Chrome for browser navigation; `app/scraper/gsmarena.py` uses BeautifulSoup for search/detail HTML parsing; `scripts/scrape_phones.py` orchestrates collection; SQLAlchemy upsert persists each success | Run `python scripts/scrape_phones.py --delay 3`, complete any Turnstile prompt manually in Chrome, then run `python scripts/verify_scraped_catalog.py --minimum 10 --maximum 15`. |
| Capture display, camera, battery life, processor and other specifications | Parsed specification sections + normalized columns include display, main/selfie cameras, battery mAh, measured active-use/endurance test results, chipset, OS, memory, connectivity, features and source URLs | Inspect `GET /api/phones/{slug}` and the `phone_specifications` table. Use `GET /api/phones/best-battery` to show measured metrics. |
| Structured PostgreSQL/MySQL database | SQLAlchemy data model; SQLite local default; PostgreSQL via psycopg, Docker Compose, `scripts/migrate_database.py` and `scripts/check_database.py` | Migrate existing SQLite rows into an empty Postgres database and confirm the script reports PostgreSQL and row counts. |
| LLM chatbot with open-source model and RAG | Existing BM25 retrieval over DB-backed phone docs/spec rows; Ollama local model generation (`OllamaClient`); model status endpoint and RAG verifier | Install/pull `qwen2.5:3b`, set `LLM_PROVIDER=ollama`, then run `python scripts/verify_ollama_rag.py`. Confirm `mode=ollama_rag`. |
| Multi-agent system with one spec retrieval agent and another review agent | `app/agents/langchain_workflow.py` uses LangChain `create_agent` twice. Specification Retrieval Agent calls the BM25/SQL evidence tool; Product Review Agent receives the handoff and calls a full-record evidence tool before generating a review | With Ollama running and addon dependencies installed, call `POST /api/reviews/samsung-galaxy-s23`; confirm `generation_mode=langchain_multi_agent`. Inspect `GET /api/agents`. |
| API integration using FastAPI/Flask | FastAPI routers for phones, comparison, battery, prices, chat, reviews, scrape and system status; browser UI and OpenAPI | Open `/docs`, query `/api/phones`, post `/api/chat`, compare S23/S22, generate review, and inspect health/LLM/agents status. |

The implementation does not count demo records as scraped records. The final submission should include screenshots/recording of the local acceptance commands and live endpoints. See `docs/V2_REVIEW_AND_FINAL_ACCEPTANCE.md` for the complete check list.
